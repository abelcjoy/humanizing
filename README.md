# Clarity for Humans

**Clarity for Humans** is a digital platform dedicated to helping individuals overcome porn addiction through science-backed tools, compassionate design, and effective cognitive behavioral techniques.

## Mission
To provide a private, judgment-free, and effective environment for users to:
1.  **Understand** the neuroscience of addiction (Dopamine, ΔFosB).
2.  **Rewire** neural pathways through daily habits and tools.
3.  **Reclaim** their time, focus, and relationships.

## Features (Planned/In-Progress)
- **High-End "Dark Mode" Aesthetic:** Reduces eye strain and sets a serious, premium tone.
- **Panic Button:** Immediate intervention tools for acute urges.
- **Daily Check-ins:** Journaling features to track mood and triggers.
- **Knowledge Base:** Educational content on the science of recovery.
- **Streak Tracking:** Visual progress indicators.

## Tech Stack
- **Frontend:** React (Vite)
- **Styling:** CSS Modules / Vanilla CSS (with modern variables)
- **Icons:** Lucide React
- **Animations:** Framer Motion
- **Deployment:** Netlify (Continuous Deployment via GitHub)
